# What the Ashes Remember

*Echoes of the Past — Curseforge ModJam 2026*

## About

A history-themed mod for NeoForge 26.1.2 where players excavate the world for 
sealed vessels: Pandora's boxes, each containing a guardian that represents a
milestone in humanity's long history of learning to destroy itself in war.
Defeating each guardian brings players closer to the final confrontation:
the force behind the ending that came before, and the ashes it left behind.

This project is under active development for the CurseForge Minecraft
ModJam 2026 and is not yet feature-complete.
